# Предварительный контракт API

Статус: проект операций, не готовая OpenAPI-схема. До реализации уточняются
типы полей, лимиты, коды ошибок, пагинация и примеры ответов. Базовый путь /api/v1.

| Операция | Назначение |
| --- | --- |
| POST /search | Выполнить поиск по запросу, фильтрам и контексту сессии. |
| GET /suggest | Получить подсказки; не регистрирует отправленный поиск. |
| GET /products/{id} | Получить продукт и варианты предложений активного снимка. |
| POST /events | Принять click/recommendation_click и другие разрешённые события. |
| GET /analytics/summary | Получить агрегаты за интервал. |
| GET /analytics/queries | Получить частые и проблемные запросы с основаниями классификации. |
| GET /searches/{id}/trace | Получить фактические этапы обработки для режима демо. |
| GET /health/live | Проверить, что процесс работает. |
| GET /health/ready | Проверить готовность обязательных компонентов. |

## Поиск

Запрос содержит query, session_id, category/segment context, разрешённые фильтры
и параметры страницы. Явные ограничения отделены от интерпретации модели.
Неизвестные поля и некорректные значения валидируются; длина запроса ограничивается.

Ответ содержит search_id, исходный запрос, исправления, использованный контекст,
версию каталога/индекса, группы результатов, сведения об ограниченном режиме,
предложения уточнения и длительность. У карточек стабильные product/offer IDs.
Пагинация требует стабильного порядка для одного контекста и версии индекса.

Ноль результатов — успешный ответ с пустыми совпадениями и объяснением.
Недоступность обязательного поискового сервиса — временная ошибка, не пустая выдача.
Недоступность OpenAI — успешный лексический ответ с явным degraded state.
Валидационные ошибки имеют стабильный машинный код и безопасное сообщение.

## События и доступ

Событие содержит event_id, search_id, session_id, тип, время и при необходимости
product/offer ID, позицию и источник клика. Backend валидирует связь с выдачей.
Повторная доставка event_id идемпотентна. Время получения хранится отдельно
от клиентского времени. Не разрешаем frontend произвольно задавать бизнес-метрики.

Аналитика и trace предназначены для локального демо. Публичное размещение требует
отдельного решения об аутентификации и доступе; режим localhost не заменяет это решение.
Секреты и необработанные ошибки SDK в ответы не включаются.
