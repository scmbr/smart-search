# Зависимые расширения ёмкости: product-role-v2

Расширение на дополнительный IP/узел/устройство не является базовой лицензией.
Пример feed: XSpider Pro SKU 540194, «Pentest + Audit на дополнительный IP,
к лицензии на 4 IP». Число исходной лицензии не доказывает ёмкость расширения.

Сначала тесты: отдельное дополнение/базовая лицензия/описание возможностей,
edition «Pentest + Audit» против комплекта «основная лицензия + расширение»,
явный запрос дополнения, отрицание, точный SKU, forged evidence, фильтр до
collapse в lexical/semantic и priced/unpriced. Затем классификатор и новый индекс.

Сильный сигнал — название SKU или продуктового узла: дополнительный IP,
IP-адрес, узел, устройство (число может стоять после прилагательного).
Обычное описание и «дополнительные возможности» не доказательство зависимости.
Явный комплект основной/базовой лицензии с расширением остаётся unknown,
а не отдельным дополнением. «Pentest + Audit» — название редакции, не такой комплект.
Общее unknown не означает подтверждённую самостоятельную лицензию.

Такие SKU получают addon/evidence, исключаются из обычной задачи до collapse.
Явный запрос дополнения и точный артикул сохраняют доступ с остальными фильтрами.
Количество дополнительных единиц и количество узлов пока не проверяются:
запрос с ними получает unsupported_query_constraints, без перевода в ПК/IP
и без суммы с исходной лицензией. Продления/обновления остаются отдельными условиями.
Наличие существующей лицензии, совместимость расширения и полнота комплекта
ещё не доказаны. Это не verifier совместимости и не гарантия четырёх товаров.

Версии: product-role-v2, lexical-v7, query-v7. Характеристики снимка не меняются:
числовые поля не объявляются достоверной ёмкостью расширений; обычный поиск
отсекает их по роли. Новая схема документа требует отдельного полного индекса.
Корпус эмбеддингов тот же, evaluation cache-only, holdout не запускать.

Аудит без целей evaluation: в полном feed 135 названий с «дополнительн…»
и IP/узлами/устройствами; это кандидаты для исследования, не 135 доказанных addon.
Среди них есть сертификация устройств и Fax over IP — одного соседства слов мало.
Дополнительные узлы в этой выборке названий не обнаружены; для них тесты synthetic.

Дополнительная приёмка после development-прогона: лицензия перехода с прежнего
продукта не заменяет базовый SKU. Точные фразы «лицензия перехода/на переход/
миграции» исключаются до collapse и повторно в application; по точному SKU
доступ сохраняется. Это проверка зависимости, а не пересчёт OfferKind.
Эти фразы используют существующий Name и не требуют ещё одного нового индекса.

## Результаты

Полный lexical-v7: 136 040 документов, 129 новых addon по правилу
identity-capacity-extension-v1. Всего addon 2 564 вместо 2 435; остальные роли
не изменились. Все 129 входят в 135 кандидатов аудита; оставшиеся шесть вне
узкого правила (включая другие единицы расширения и сертификацию устройств).
Это не независимая оценка precision и не полный справочник зависимых лицензий.

Индекс smart-search-eb46ed92f8e3672f04c5642468adab5546c5d4e45bca91e53eb607c705030a50:
сборка 237 067 мс, PostgreSQL reuse 75 мс. Counts каждого из прежних
58 семейств / 108 групп совпали с feed, 6 374 подтверждённых предложения.
Снимок characteristics-v5, family mapping и эмбеддинги не менялись;
старый индекс сохранён, приватные временные файлы удалены.

Tuning: 52/52 групп, 6/6 брендов, 2/2 отрицательных. Development: 7/16 вместо
8/16 после purpose-v1. Probe-03 раньше засчитывался за addon 540194, затем
за лицензию перехода 540220. Все 19 ценовых non-addon/non-renewal/upgrade SKU
группы XSpider Pro 428013 — переходные; самостоятельный подходящий SKU этой
группы в этом приоритете не подтверждён. Цель не менялась, потеря попадания
зафиксирована, четыре релевантных семейства не доказаны.

Smoke: точные 540194 и 540220 доступны, явный запрос «XSpider дополнительный IP»
возвращает addon 540239. Количество дополнительных единиц, контекст «к лицензии
на 4 IP» и количество узлов — not_searched/unsupported_query_constraints.
Тесты domain/application, real ES (включая before-collapse/точный SKU/unpriced),
Go/vet/build/gofmt и восемь Python-тестов прошли. OpenAI не вызывался,
holdout не запускался. Локальные отчёты capacity-extensions-*.json/jsonl
и capacity-extension-inventory.json находятся в artifacts/, в Git не включены.
