# Расширение семейств: families-v3

## Граница и приёмка

Расширить подтверждённые правила за пределы десяти исходных сценариев. Рабочая
область — выбранные продукты девяти vendor scopes уже исследованного каталога;
это расширение, не полная разметка 136 040 предложений. Источники — названия
продуктовых узлов и SKU того же feed, без поисковой выдачи и суждений holdout.

Версии, редакции, платформы и способы приобретения одного продукта занимают
один family_id. Отдельные продукты остаются разными. По одному vendor или
общему слову в названии семейство не подтверждается. Спорные группы остаются
provisional и не участвуют в подтверждении четырёх семейств.

До реализации: тесты объединения Office, Visio, Windows, SQL Server, KES,
планов МТС Линк; тесты разделения самостоятельных продуктов и неверного scope.
После: полный аудит каждой группы/её SKU, новый индекс, real ES collapse,
повтор индекса без дублей, tuning/reference без запуска holdout.

## Решения о границах

- Office: пакеты Home/Business/Standard/Professional, годы, Mac и программы
  лицензирования объединяются. Отдельные Word, Excel, Outlook, PowerPoint,
  Access и Publisher — самостоятельные продукты. Microsoft 365 отдельно.
- Microsoft 365 Family/Personal объединяются; бизнес-планы пока provisional.
- Visio Standard/Professional объединяются; Project Desktop отдельно от Visio
  и от пока неподтверждённых Project Server/Online/CAL.
- Windows Desktop: 10/11 и Home/Pro/Enterprise — одна семья. Windows Server
  с явными собственными CAL — другая; RDS и External Connector не добавляются.
- SQL Server: редакции, собственные CAL и Open Value — одна семья;
  Microsoft R Server и другие продукты не добавляются по слову Server.
- KES для бизнеса: Стандартный/Расширенный/Расширенный Плюс — одна семья.
  Small Office и Security для почтовых серверов объединяют свои подписные группы.
  Kaspersky Cloud/Total/consumer bundles не объединяются без отдельного разбора.
- МТС Линк: Optimum/Стандарт/Про не увеличивают число семейств.
- XSpider/PRO — одна семья. УЦ КриптоПро: базовые лицензии/ПАК/дополнительные
  компоненты не считаются тремя семействами. CSP TLS/JavaCSP/JCP пока provisional.
- Самостоятельные инструменты Astra, Киберпротект и Эшелон добавляются по явным
  названиям узлов. Termidesk/Connect, Astra Cloud/Clouden и облачный/Старт Бэкап
  остаются provisional до проверки границ и возможных переименований.

## Происхождение и версии

rules.json — исполняемое правило; family-evidence.json — воспроизводимые counts,
vendor scope и примеры SKU каждой группы. Для исходных семейств сохранены ссылки
из reference; для новых SourceURL — реальная ссылка SKU из feed, не выдуманная
страница продукта и не подтверждение вендором. Каталожное подтверждение семейства
не доказывает соответствие запроса, условия покупки или совместимость.

Изменение families-v3/SHA правил требует новой индексации; нормализация признаков
и формат документа не меняются. Повторный импорт feed не нужен. Старый индекс
сохраняется; alias переключается только после полной готовности нового.

Команды аудита и ограничения — [evaluation-review.md](evaluation-review.md).

## Выполненные проверки 2026-11-27

- До изменения правил тест воспроизвёл отсутствие объединения Office 391335 с
  microsoft-office. После изменения прошли тесты всех выбранных объединений,
  разделения самостоятельных продуктов, неверного vendor scope и provisional.
- Unit/application/контрактные тесты и реальные PostgreSQL/Elasticsearch прошли.
  Интеграционный тест с production-конфигом: четыре SKU Office/Visio дают два
  подтверждённых семейства; неизвестная группа не увеличивает этот счётчик.
  Фильтр редакции выбирает подходящий SKU до collapse.
- Полный аудит feed повторён и совпал с frozen evidence. Новый индекс содержит
  136 040 документов; counts всех 50 семейств/95 групп в Elasticsearch точно
  совпадают с извлечёнными из feed, подтверждённых предложений — 6 257.
- Индексация заняла 173,570 с; повтор — 82 мс, Reused=true, без записи/дублей.
  Snapshot не менялся: a782a39020b3a065a7d8a0b2fd3ce72687d61d2ff49b476c660d6827604bcdb2.
  Новый индекс: smart-search-d284b9ac878ff15ca3bbded8d4e749819016cf8895fa94f78f362b598e18c192.
  Family version: families-v3-0934a9c1b87463d9a3778d0fdeed773583ae07a1375550993acddf355e84c064.
  Нормализация characteristics-v4, схема lexical-v4 и query-v3 не менялись.
- Те же 60 tuning-кейсов: group targets 43/52, brand scopes 6/6,
  отрицательные 2/2, execution errors=0. Исходы каждого кейса по этим метрикам
  не изменились относительно families-v2; это не независимая оценка качества.
  Четыре ранее исправленных запроса сохранили нужный SKU на первом месте.
- Reference smoke — прежние 9/10 (7/8 групповых и 2/2 широких). Четыре
  подтверждённых семейства не обеспечены ни в tuning, ни в reference;
  поиск допродаж и полноценная проверка SKU остаются будущими задачами.
- Принятые 100 кейсов не менялись. Holdout не запускался, OpenAI API не вызывался.
