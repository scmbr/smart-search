# Проверка назначения: purpose-v1

До реализации: тесты OS против управления OS, замены AD против инструментов
для существующей AD, неизвестного/vendor mismatch, обхода через backend.

Для явного запроса операционной системы проверяются выбранные продуктовые
группы Astra Linux SE, РЕД ОС и РОСА ХРОМ. Для явной альтернативы Active
Directory — ALD Pro и Альт Домен. Это ограниченное покрытие, unknown исключается
из этих запросов, но не из остальных. Отрицания и запросы управления системой
не активируют фильтр замены. Используется только исходный запрос, не LLM rewrite.

Фильтр group_id + точный vendor URL применяется до collapse в lexical и
semantic resolve; application повторяет проверку. Индекс/семейства не меняются:
используются существующие поля. Query policy повышается до query-v6.

Источники:

- [ALD Pro, служба каталогов и домен](https://www.aldpro.ru/).
- [Альт Домен и переход с AD](https://www.basealt.ru/alt-domain).
- [РЕД ОС](https://redos.red-soft.ru/product/red-os/).
- Astra Linux SE и РОСА ХРОМ: названия и категории feed; маппинг уже исследован.

Назначение продукта не подтверждает редакцию, сертификацию, права организации,
количество контроллеров, наличие ОС в комплекте или совместимость.
Дополнительная приёмка: образовательный SKU не проходит без образовательного
контекста; для замены AD требуется явное указание серверной лицензии или
контроллера домена в SKU. Клиентские/неизвестные права не достаточны.
Проверка лицензионных прав, образовательных ограничений и дополнительных IP/узлов
остаётся открытой; четыре подходящих товара случайными кандидатами не заполнять.
Holdout не использовать; development повторять только из кэша.

Результат cache-only: tuning 52/52 групп, 6/6 брендов, 2/2 отрицательных,
development 8/16 против 7/16. Запрос AD: 470013, 445080, 494940 — Альт Домен
двух поколений и серверная ALD Pro. Это не три подтверждённых разных семейства.
Запрос ОС: 499386 (РЕД ОС рабочая станция) и 400741 (РОСА ХРОМ сервер).
Образовательный 499381, РОСА Центр Управления и РЕД АДМ отсеяны.
Пригодность серверной конфигурации для рабочих станций здесь не доказана.

Unit domain/application, real ES до collapse (unknown/образование/сервер AD),
vet/build и полный Go-прогон проверены. Локальные отчёты в artifacts/:
purpose-v1-tuning-final.json и purpose-v1-probes-final.json. OpenAI не вызывался,
holdout и цели наборов не менялись. Назначение не заменяет проверку лицензирования.
