# Поиск Windows: query-v9

Запросы «виндовс», «виндоус» и «винда» получают канонический вариант windows.
Остальные опечатки по-прежнему обрабатываются общими ограниченными fuzzy-правилами;
словарь не является перечнем всех поддержанных запросов.

Явное начало запроса Windows / Microsoft Windows, в том числе после слов
«лицензия», «новая лицензия», «купить», «продление», «обновление», «поддержка»,
активирует назначение windows_operating_system. Требуются одновременно:

- ProductType=software;
- категория «Операционные системы»;
- отдельное слово Windows в ProductName.

Фильтры применяются до collapse во всех lexical-попытках и semantic resolve;
application повторяет проверку конкретного SKU и доверенного URL каталога.
Упоминание Windows только в описании совместимости не подтверждает идентичность.
«Плеер для Windows», «ПО для Windows» и отрицания не включают фильтр самой ОС.
Версии, артикулы, роли SKU и priced-first fallback сохраняют прежние ограничения.

Используются существующие поля lexical-v7: перестроение индекса и новые
эмбеддинги не требуются. Это ограниченное распознавание Windows, а не общий
классификатор всех продуктов. Категория и имя не доказывают лицензионные права,
совместимость и наличие четырёх разных семейств. Неизвестное назначение исключается
из запроса самой Windows. Публичный API-контракт не меняется.

Приёмка: domain-тесты алиасов/контекста/доказательств; отдельный реальный ES-индекс
с ОС, плеером, другой ОС и оборудованием; версии, точный артикул и неизвестная цена.
Измерения development выполняются только из кэша, holdout для настройки не используется.

## Выполненная проверка

Go vet/build и полный go test с PostgreSQL/Elasticsearch прошли; дополнительный
application-тест отклоняет ошибочную выдачу адаптера. Python: 13 тестов прошли.
Cache-only tuning: group@1/@4 52/52, brand 6/6, negative 2/2; development:
group@1 6/16, group@4 8/16, execution errors=0. Значения не ухудшились.
Компактный отчёт: [windows-search-development-v1.json](../testdata/evaluation/windows-search-development-v1.json).

После перезапуска API реальный Vite proxy подтвердил: «виндовс», Windows и
«виндовс 11» → Microsoft Windows 11 Pro FQC-10572; «плеер для виндовс» → Сарма.
Для самой Windows получено одно подтверждённое семейство. Это HTTP-проверка,
визуальная браузерная QA не выполнена. OpenAI не вызывался, holdout не запускался.
