# Пилот эмбеддингов

## Граница

Измерить кандидатов и стоимость до полной индексации. Production-поиск, его
alias и SKU-фильтры не меняются. Векторы не доказывают совместимость/право покупки.
Holdout не читать и не запускать; принятые 100 кейсов не менять.

Corpus embedding-text-v1: до 512 групп из feed, все группы девяти изученных
vendor scopes плюс остальные по SHA-256 ключа. Название узла, категория и
описание одного представительного SKU, максимум 2048 UTF-8 байт; без цены/наличия.
Не объединять характеристики разных SKU. Сохранить SHA feed, IDs и источники.
Состав фиксируется до измерения. Дополнительные task probes — отдельные
синтетические development-кейсы, не независимый эталон релевантности.

## Модель и расходы

- [text-embedding-3-small](https://developers.openai.com/api/docs/models/text-embedding-3-small):
  $0.02 / 1M input tokens, проверено 2026-11-27. 1536 измерений;
  дополнительно сравнить первые 512 с cosine/L2, без повторного API-вызова.
- [Руководство](https://developers.openai.com/api/docs/guides/embeddings):
  API поддерживает сокращение векторов; локальная проекция отмечается отдельно
  от dimensions=512 в запросе. Измерять кандидатов, не end-to-end SLO.
- До запроса резервировать верхнюю стоимость по UTF-8 bytes + 16 на текст,
  а не выдавать приближение за точный tokenizer. Реальные токены — только API usage.
- Цена в nanodollars: 20 за токен. Бюджет проекта 5 USD сохраняется в PostgreSQL,
  не обнуляется при рестарте. Незавершённый/ошибочный запрос удерживает весь резерв.
  Успешный usage в пределах резерва атомарно фиксируется вместе с кэшем.
- Лимит одного запуска 0.05 USD; batch <=32, параллелизм 1, SDK retries=0,
  timeout 30 с. Нет автоматических повторов с возможным двойным списанием.
- Кэш по версии текста/model/dimensions/SHA текста, без секретов. Повреждённые,
  пустые/нечисловые векторы и некорректные индексы ответа отклоняются.

SDK: официальный openai-go/v3 v3.20.0, Apache-2.0, go 1.22 совместим с проектом
Go 1.25. Текущий master требует Go 1.26; toolchain ради пилота не повышается.
[Исходники версии](https://github.com/openai/openai-go/tree/v3.20.0).

## Сравнение

Одинаковый corpus/text для cosine и отдельного временного Elasticsearch BM25
(русский анализатор, raw query, OR, без query-v4/фильтров SKU). Индекс пилота
не имеет production alias; удаляется только при совпадении собственного owner.
Текущие 52/52 production tuning — отдельная диагностика, не этот контроль.

Показывать known-positive group hit@4 отдельно для tuning и probes, brand scopes
отдельно. Набор ограничен, суждения не исчерпывающие; не заявлять Precision/nDCG
или независимую точность. Отрицательные запросы показывают необходимость отказа:
top-k векторов всегда возвращает ближайшие группы, даже если товар не подходит.

## Приёмка

Сначала domain/application-тесты: границы текста/стоимости, cosine, разделение
наборов, кэш/replay без сети, резерв до API, отказ бюджета, неизвестный исход.
Затем HTTP-моки SDK (индексы/usage/ошибки без секретов), реальные PostgreSQL
транзакции/конкуренция и временный ES. Обычные тесты без платных запросов.
После dry-run с конкретной оценкой — ограниченный live-пилот и повтор из кэша.
Факт измерения отмечать только после ответа API; ошибки аккаунта не считать успехом.

## Команды

Из корня, с работающими PostgreSQL/Elasticsearch и локальным .env:

```powershell
python scripts/prepare-embedding-pilot.py --feed "C:/Users/hypoc/Downloads/Mindbox.yml.gz.xml"
go build -o bin/embedding-pilot.exe ./cmd/embedding-pilot
bin/embedding-pilot.exe -mode plan -output artifacts/embedding-pilot-plan.json
# Только для разрешённого пользователем корпуса/платного запуска:
$env:OPENAI_LIVE_ENABLED = 'true'
bin/embedding-pilot.exe -mode live -output artifacts/embedding-pilot-live.json
$env:OPENAI_LIVE_ENABLED = 'false'
bin/embedding-pilot.exe -mode replay -output artifacts/embedding-pilot-replay.json
```

Миграция 002 применяется CLI автоматически. В этой локальной среде для SQL
использован PGOPTIONS='-c max_parallel_workers_per_gather=0 -c jit=off'.
Replay не создаёт провайдер OpenAI и работает без ключа, но требует локальную БД
с кэшем и Elasticsearch для повторного BM25-контроля. При пропуске кэша — ошибка,
а не неявный платный запрос. Global budget атомарно сериализует резервирование
между процессами. Кэш пока не предотвращает одновременную оплату одинакового
промаха несколькими процессами; это ограничение до production-доработки.

## Фактический прогон 2026-11-27

Пользователь явно разрешил отправить OpenAI эти 512 текстов и 76 запросов и
выполнить платный пилот. Исходные поля price/available и секреты не включались;
текстовые названия могут содержать слова «цена за лицензию», без значения цены.
До разрешения live-запуск был отклонён автоматической проверкой одобрения;
он не выполнился, платных запросов в тот момент не было.

Dataset SHA (канонический Go JSON):
b9512910badb491301de61174b37d40987b389563636be487fca00292a0ea828.
SHA исходного feed прежний: 27eaec9e77942c61d58b3c04dcaa8991c707dc0fcb64a6442a7408d9908cb148.
Состав 60 tuning не менялся. SHA 16 probes до API:
af7a01d9bf904948afc338accfc70a6003a8931680b1b77c10f5b3daf538dc84.
Положительные ссылки не исчерпывают все релевантные альтернативы; семантика
ALD Pro/Tantor/GitFlic/Astra Monitoring дополнительно проверена по источникам,
записанным в embedding-probes-v1.json. Они не добавлялись в текст эмбеддинга.

586 уникальных текстов: 19 API batches, **59 656 input tokens**, usage-derived
стоимость **0.00119312 USD** по проверенному тарифу. Байтовая верхняя оценка до
запуска — 228 830 tokens / 0.00457660 USD. Это не выписка биллинга аккаунта.
Ledger после запуска: actual=1 193 120 nanodollars, reserved/uncertain=0;
остаток бюджета проекта **4.99880688 USD**. Replay без API-ключа: cache hits=586,
cache misses=0, requests=0, cost=0; ledger до/после полностью совпал.

| Development-набор | Случаев с известной положительной группой | Raw BM25 | Cosine 1536 | Cosine prefix 512 |
| --- | ---: | ---: | ---: | ---: |
| Tuning, именованные/смешанные запросы | 52 | 40 | 44 | 44 |
| Дополнительные задачи без названия продукта | 16 | 7 | 12 | 13 |

Brand scopes: BM25 5/6, оба vector-варианта 6/6. Для двух отрицательных tuning
запросов векторы вернули ближайшие группы; порог отказа не подбирался.
Это известные положительные попадания в top-4 групп ограниченного корпуса,
не Precision, независимая точность или оценка выполнения условий лицензии.
Production query-v4 с правилами/фильтрами имеет 52/52 на tuning другого конвейера;
с этими raw candidate-метриками его напрямую не сравнивать.

Для probes: 7 попаданий только у vector-512 и 1 только у BM25; для tuning —
7 только у vector-512 и 3 только у BM25. Это свидетельство дополнения кандидатов,
а не измеренный результат RRF. В частности, векторные варианты пропустили
известную цель российского ОС-запроса, где BM25 попал; отдельные верные
альтернативы вне положительных списков могут считаться промахом этой диагностики.

Batch API latency: median 558.292 мс, nearest-rank p95/max 3834.686 мс.
Локальный расчёт обоих cosine-вариантов для 76×512 — 386 мс суммарно.
Batch latencies не являются p95 пользовательского поиска.

Полный offline-проход оценил 12 538 group/offer-fallback документов и 136 040 SKU.
Для той же схемы текста верхние стоимости: группы 0.08975356 USD,
SKU 1.23599116 USD. Это границы по байтам/тарифу, не оплаченная полная индексация.
Групповой вектор не заменяет выбор конкретного SKU и строгие фильтры.

Решение: сохранить BM25 и строгие условия, продолжить гибридный эксперимент;
512 измерений — кандидат для следующего шага (в 3 раза меньше координат),
а не доказанно оптимальная размерность. В полном индексе пока ничего не менять.
RRF, отказ по недостаточной релевантности и production-кэш/повторы ещё предстоят.

Следующий шаг выполнен в [общем исполнении эмбеддингов](embedding-runtime.md):
live/replay используют Runtime с общей дедупликацией и ограниченными повторами.
Описанные выше исходные измерения относятся к пилоту до этой доработки.

Активный alias до/после совпал, временные pilot-индексы удалены по owner,
обычный поиск не изменён. Holdout не читался/не запускался.
Локальные артефакты в artifacts/: embedding-pilot-{dataset,plan,live,replay}.json,
embedding-pilot-active-{before,after}.json. Векторы и ledger хранятся локально в БД.
